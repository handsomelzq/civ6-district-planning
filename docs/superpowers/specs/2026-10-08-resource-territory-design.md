# 资源落位与城市领土设计

状态：用户已要求按《文明 VI》资源规则修正区域落位，并为相邻城市生成明确且不重叠的边境。本设计按推荐方案进入 Native 实现。

## 1. 范围

本轮只修改资源占用、城市中心资源例外、城市领土归属、区域跨城限制和地图边境表现。相邻产出、人口配额、水系、随机气候、政策、科技、市政、宗教和军事规则保持原状。

## 2. 资源规则

`resources.csv` 增加 `是否可收获` 与 `收获前置科技`。数据来自风云变幻最终加载结果的 `Resource_Harvests`；没有该表记录的资源不可通过普通收获移除。

- 奢侈、战略、文物和魔力节点资源阻止区域放置。
- 加成资源也不能直接被区域覆盖。
- 自由模式提供“清除加成资源”工具。只有 `是否可收获=是` 且前置科技全部解锁时才能清除；清除后才能放区域。
- 城市中心可落在资源上，资源保留。
- 本轮不结算收获资源获得的粮食、生产力或金币，也不模拟建造者次数。

## 3. 城市领土

多城局面使用所有市中心同步划分领土。每个地图地块在城市中心三格范围内选择距离最近的城市；同距时使用稳定的坐标散列在候选城市间分配，保证每格最多一个归属，并让相邻城市间的分界略有起伏。超过所有城市三格范围的地块保持中立。

城市中心格永远归属自身城市。移动城市中心后领土即时重算。这个分区是 Demo 的静态规划规则，不是《文明 VI》文化扩张、购买地块或换城系统的复刻。

## 4. 放置合法性

自由模式选择城市后，区域目标格必须满足：

1. 属于所选城市领土；
2. 在该城市三格工作范围内；
3. 通过既有地形、地貌、资源、研究、人口和唯一性约束。

目标格为中立领土或另一座城市领土时返回 `E16b`。完整局面校验也检查已放置区域的 `所属城市` 是否仍与当前领土一致；移动城市中心导致的旧区域越界会进入诊断。

## 5. 表现

地图地块保留低透明度的城市领土色。边境单独作为 SVG 层生成：

- 同一城市相邻地块之间不画线；
- 城市领土与中立地块之间画该城市颜色的外边界；
- 两座城市相邻时只画一次共享边界；
- 不再给每个领土地块绘制完整彩色六边形边框。

## 6. 验收

- 三类资源与城市中心例外均有共享合法性测试。
- 可收获加成资源在科技解锁前后有清除工具测试。
- 两座间距 4 的城市在重叠工作范围内每格唯一归属，等距格不留裂缝。
- 区域在本城领土可建，在另一城市领土和中立地块被 `E16b` 拦截。
- SVG 城市共享边只输出一次，领土内部边不输出。
- 移动城市中心后资源仍在，领土和阻断预览随新中心更新。
- 完整 Node 测试、配置校验、构建检查和实际浏览器交互通过后才交付。
