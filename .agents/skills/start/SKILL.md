# 接续已有区域规划项目

先读取[项目约定](../../../AGENTS.md)、[上下文](../../../studio/project-context.md)与[制作管理视角](../../../studio/roles/producer.md)。

1. 确认当前工作目录，读取项目 README、task_plan.md、progress.md 和 git status；根据任务按需读设计文件。
2. 默认识别为已有 TypeScript + Web 项目，列出实际完成、进行中和待核内容；不重复问是否已有创意或强制用户重选引擎。
3. 用当前源码和测试校对旧状态；旧文档中的测试数、关卡缺口和迁移想法不是现状证明。
4. 输出一个短清单：当前目标、关键文件、证据、阻碍和推荐下一步。用户已明确要求继续的工作直接接续。
5. 需要留档时新增或更新 production 下本任务记录；不覆盖已有专项计划，不自动把未批准建议记为需求。

需要用户选择新方向时集中呈现少量带代价的选项；已知上下文不重复询问。
本技能不要求上游 adopt、review-mode.txt 或完整制作阶段档案。
