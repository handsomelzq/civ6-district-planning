# 任务卡模板

仅在有实际任务时复制到 `production/stories/`；模板不代表已批准需求。

- 状态：Draft / Ready / In progress / Done / Blocked（按真实状态填写）
- 玩家／学习目标：
- 设计依据：现有 GDD／SDD 的具体章节，或用户确认的指令。
- 范围与不涉及项：
- 影响文件与数据来源：
- 依赖及待确认项：

## 验收条件

用“给定局面／前置状态 → 操作 → 可观察的结果”描述每条条件。
数值任务写出来源与期望明细；UI 任务写出需要实际验证的反馈。

## 验证记录

填写实际执行命令、退出码、报告路径；分别记录通过、失败和未测项。
自动测试与试玩分别记录，不以其中一种替代另一种。

## 完成说明

填写实现变化、偏离原方案的原因、剩余限制。满足验收后才改成 Done。
