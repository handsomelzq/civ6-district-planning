# 文明 VI 官方 UI 图标

此目录中的 175 个 PNG 图标来自本机 Steam 安装的《Sid Meier's Civilization VI》 `CIVBLP` 资源包，`manifest.json` 记录每个图标的来源图集和索引。它们会随本项目网页发布，仅用于个人使用与求职展示。

提取时参照的 MIT 开源解析实现：

- https://github.com/MalTeeez/civ-6-map-viewer/blob/main/scripts/extract_icons.ts
- https://github.com/flat-arther/Civ-VI-Accessibility-Integration/blob/main/scripts/Extract-GreatWorksBlp.py
